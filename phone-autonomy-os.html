Find the true constraint: environment | task difficulty | attention | emotion | notifications

Choose the highest leverage point. Don't fix ten things; fix the one that matters most.

Skill design → Minimum intervention → Action → Feedback → Error recognition → Update → Retest

📵 手機離視線Skill【環境刺激型】 ▼
Phone Out of Sight Skill 【Visual Stimulus Type】
  • 手機放書包最內層 → Put phone in innermost pocket of backpack
  • 手機放教室指定位置 → Keep phone at designated classroom location
  • 進教室前手機離開桌面 → Remove phone from desk before entering class
核心原理
降低刺激的可見性 = 降低衝動觸發機率
Core Principle
Reduce visibility of temptation = Reduce impulse trigger frequency
🔕 通知斷流Skill【通知觸發型】 ▼
Notification Cutoff Skill 【Trigger Type】
  • 關閉非必要通知 → Turn off non-essential notifications
  • 取消震動 → Disable vibration
  • 移除鎖定畫面預覽 → Remove lock screen previews
  • 設定勿擾模式時段 → Set Do Not Disturb schedules
核心原理
外在刺激消失 = 自動衝動消失
Core Principle
Remove external triggers = Eliminate automatic impulses
⏱️ 10分鐘專注Skill【注意力週期型】 ▼
10-Minute Focus Skill 【Attention Cycle Type】
  • 不要求專心一整節 → Don't demand full-class focus
  • 只要求先完成10分鐘 → Only require 10 minutes to start
  • 設置小型獎賞間隔 → Set mini-reward intervals
  • 10分鐘後允許短暫休息 → Allow brief breaks after 10 minutes
核心原理
降低心理負擔 = 更容易開始
Core Principle
Lower psychological burden = Easier to start
✂️ 任務拆解Skill【任務太大型、啟動困難型】 ▼
Task Breakdown Skill 【Overwhelm Type】
  • 「讀英文」→ 先讀第一段 → "Read English" → Start with paragraph 1
  • 圈3個關鍵字 → Circle 3 keywords
  • 回答第1題 → Answer question 1
  • 每一步都小到不需要手機逃離 → Each step small enough to avoid phone escape
核心原理
小任務 = 低逃避誘因
Core Principle
Micro-tasks = Reduced escape temptation
🚀 5分鐘啟動Skill【啟動困難型】 ▼
5-Minute Startup Skill 【Activation Barrier Type】
  • 不要求完成 → Don't demand completion
  • 只要求開始5分鐘 → Only require starting for 5 minutes
  • 5分鐘後「如果還想做就繼續」 → "Continue if you want to" after 5 minutes
  • 重點是跨越啟動障礙 → The goal is crossing the activation barrier
核心原理
開始比完成重要 = 動力會跟上來
Core Principle
Starting is harder than continuing = Momentum follows
⏸️ 延遲衝動Skill【習慣自動型、即時獎賞型】 ▼
Impulse Delay Skill 【Automatic Habit Type】
  • 想拿手機時先等60秒 → Wait 60 seconds before picking up phone
  • 可以數數、喝水、走動 → Count, drink water, or move around
  • 60秒後決定是否真的需要 → Decide afterward if you really need it
  • 大多數衝動會在延遲中消失 → Most urges disappear during the delay
核心原理
衝動是波浪 = 等等就過
Core Principle
Urges are like waves = They pass with time
🅿️ 手機停車場Skill【環境誘惑型、習慣自動型】 ▼
Phone Parking Lot Skill 【Habit Automation Type】
  • 進入教室前手機固定停在同位置 → Keep phone at same spot before entering class
  • 每次都放在同一個地點 → Same location every time
  • 養成「手機停車場」的習慣 → Establish "phone parking lot" habit
  • 下課再取回 → Retrieve it after class
核心原理
習慣化 = 環境自動執行
Core Principle
Habit automation = Environment executes for you
🚫 短影音阻力Skill【即時獎賞型、FOMO型】 ▼
Short Video Friction Skill 【Immediate Reward Type】
  • 把高誘惑APP移出首頁 → Move addictive apps off home screen
  • 登出帳號 → Log out of accounts
  • 設定使用限制 → Set usage limits
  • 增加開啟步驟 → Add extra steps to open
核心原理
摩擦增加 = 衝動的代價升高
Core Principle
Friction beats willpower = Higher cost of impulse
🛏️ 睡前關機Skill【睡眠不足型、習慣自動型】 ▼
Bedtime Shutdown Skill 【Sleep Deprivation Type】
  • 睡前固定時間設定鬧鐘 → Set alarm at fixed pre-sleep time
  • 鬧鐘響→手機離床 → When alarm rings → phone leaves bed
  • 手機放充電區（不在臥室） → Charge phone outside bedroom
  • 保護睡眠時段 → Protect your sleep window
核心原理
好睡眠 = 隔天更有自控力
Core Principle
Good sleep = More self-control tomorrow
🔄 替代行為Skill【無聊型、焦慮逃避型】 ▼
Alternative Behavior Skill 【Avoidance Type】
  • 無聊時不能只說「不能滑手機」 → Don't just say "no phone"
  • 提供具體替代：喝水、伸展、走動 → Offer alternatives: drink, stretch, walk
  • 整理桌面、看一頁書 → Organize desk or read one page
  • 替代品要更容易取得 → Alternatives must be easier to access
核心原理
天性討厭空白 = 提供更好的選項
Core Principle
Nature abhors a void = Offer better options
😌 情緒辨識Skill【情緒調節型、焦慮逃避型】 ▼
Emotion Recognition Skill 【Emotion Regulation Type】
  • 想滑手機時先暫停 → Pause before reaching for phone
  • 問自己：無聊？焦慮？挫折？孤單？疲累？ → Ask: Bored? Anxious? Frustrated? Lonely? Tired?
  • 針對情緒選擇對應行動 → Choose action matching the emotion
  • 例如：焦慮→深呼吸，孤單→傳訊息給朋友 → E.g.: Anxious→breathe, Lonely→message friend
核心原理
看見情緒 = 不被情緒自動駕駛
Core Principle
See the emotion = Break automatic reaction
🏔️ 任務降難Skill【任務太難型、焦慮逃避型】 ▼
Task Difficulty Adjustment Skill 【Hard Task Type】
  • 任務太難導致逃避 → Hard tasks trigger escape
  • 降低第一步難度 → Lower difficulty of first step
  • 或尋求資源協助 → Or seek resource help
  • 先完成簡單版本，再挑戰難版本 → Easy version first, then hard
核心原理
難度適中 = 專注力在
Core Principle
Right difficulty = Sustained focus
🎁 獎賞延遲Skill【即時獎賞型】 ▼
Reward Delay Skill 【Immediate Gratification Type】
  • 完成25分鐘任務 → 才能用5分鐘手機 → After 25 min task → 5 min phone time
  • 不是禁止獎賞，是延遲獎賞 → Not no reward, but delayed reward
  • 視覺化進度（例如番茄鐘） → Visualize progress (e.g., Pomodoro timer)
  • 獎賞要夠吸引，才值得等待 → Reward must be compelling enough to wait for
核心原理
延遲滿足 = 大腦執行功能訓練
Core Principle
Delayed gratification = Executive function training
🔋 專注恢復Skill【注意力週期型、睡眠不足型】 ▼
Focus Recovery Skill 【Attention Cycle Type】
  • 注意力掉下來時短暫恢復 → Brief recovery when focus drops
  • 30秒眼睛休息（看遠方） → 30-second eye break (look far away)
  • 2分鐘走動、喝水 → 2-minute walk and hydration
  • 然後再進下一輪專注 → Then back to focus cycle
核心原理
週期性恢復 = 延長總專注時間
Core Principle
Periodic recovery = Extended total focus time
🎯 目標連結Skill【缺乏目標型、FOMO型】 ▼
Goal Connection Skill 【Low Purpose Type】
  • 把「不玩手機」連結到更大的目標 → Link "no phone" to bigger goal
  • 例如：「我要考上理想科系」 → E.g.: "I want to get into my dream school"
  • 「我要保持睡眠品質」 → "I want to maintain sleep quality"
  • 每當想拿手機時，想起這個目標 → Recall this when tempted
核心原理
內在動機 > 外在禁止
Core Principle
Internal motivation > External prohibition

💡 核心洞見 | Core Insights

洞見1
真正的自律不是：「我可以一直忍。」
真正的自律是：「我知道如何重新設計自己的系統。」
Insight 1
True discipline is NOT enduring willpower. It's knowing how to redesign your system.
洞見2
真正的自由也不是：「我想滑就滑。」
而是：「手機在我旁邊，我仍然擁有選擇下一個行動的能力。」
Insight 2
True freedom is NOT "scroll whenever I want." It's having choice even when tempted.
洞見3
最終進化：老師控制 → 規則控制 → 環境控制 → 學生自我觀察 → 學生自我調節 → 學生自我更新 → 外部控制逐漸撤除
Insight 3
Evolution: External control → Rules → Environment → Self-observation → Self-regulation → Self-update → Independence
