本體層 Essence Level
語言不是單純說話，而是大腦切割、編碼與理解現實的工具。
Language is not merely speaking, but a tool through which the brain segments, encodes, and understands reality.
結構層 Structure Level
低維語言偏人格、對錯、固定、單因果；高維語言偏變數、關係、機制、系統、模型。
Low-dimensional language focuses on personality, right/wrong, fixed states, and single causality; high-dimensional language emphasizes variables, relationships, mechanisms, systems, and models.
機制層 Mechanism Level
語言→內在表徵→注意力→預測→決策→行動→結果→回饋→模型更新。
Language → Internal Representation → Attention → Prediction → Decision → Action → Result → Feedback → Model Update.
行動層 Action Level
遇到問題時，不急著判斷自己或別人，而是進入「事實→變數→Pattern→機制→Hypothesis→測試→Prediction Error→更新」。
When facing problems, don't rush to judge yourself or others. Instead, enter the flow: Facts → Variables → Patterns → Mechanisms → Hypotheses → Testing → Prediction Error → Update.

12階認知進化 12-Stage Cognitive Evolution
第01階｜情緒 Emotion
我現在感覺什麼？ What am I feeling?
第02階｜事實 Facts
實際發生什麼？ What actually happened?
第03階｜資料 Data
頻率、程度、時間是多少？ Frequency, degree, timing?
第04階｜變數 Variables
哪些因素可能影響？ What factors influence?
第05階｜Pattern
什麼事情反覆發生？ What repeats?
第06階｜關係 Relationships
變數如何互相作用？ How do variables interact?
第07階｜機制 Mechanism
Pattern如何被生成？ How is pattern generated?
第08階｜系統 System
什麼結構讓它持續存在？ What structure sustains it?
第09階｜模型 Model
我現在如何解釋這套系統？ My current explanation?
第10階｜預測 Prediction
如果模型正確，接下來應該發生什麼？ Expected outcome?
第11階｜誤差 Error
現實與預測差在哪裡？ Where's the gap?
第12階｜更新 Update
下一版模型與行動要修改什麼？ What changes next?
六大語言家族 Six Language Families
第一族｜去失真語言 Distortion-Removal
事實 · 證據 · 資料 · 訊號 · 訊噪 · 可信度
目的：不要被自己的故事騙
第二族｜診斷語言 Diagnostic
變數 · Pattern · 關係 · 機制 · 節點 · 瓶頸
目的：找到問題真正生成的位置
第三族｜模型語言 Model
Hypothesis · 機率 · 先驗 · 後驗 · 反證 · 可證偽
目的：不要把想法當真理
第四族｜更新語言 Update
Feedback · Prediction Error · Calibration · Model Update
目的：讓錯誤真正產生學習
第五族｜行動語言 Action
槓桿 · Priority · Experiment · Trigger · Environment
目的：用最低成本改變系統
第六族｜生成語言 Generation
Skill · Transfer · Adaptation · Resilience · Agency
目的：讓一次解題變成永久能力
六問工作法 Six-Question Framework
問1：事實是什麼？ What are the facts?
問2：什麼Pattern正在重複？ What pattern repeats?
問3：什麼機制正在生成它？ What mechanism generates it?
問4：現在最大的瓶頸／槓桿在哪？ Where's the bottleneck?
問5：我的Hypothesis怎麼用最小實驗測試？ How to test minimally?
問6：Prediction Error告訴我要更新什麼？ What to update?

核心公式 Core Formula
現實→語言→模型→預測→行動→結果→回饋→更新

語言位在整個控制迴路最前端。
前端編碼失真，後面再努力都只是精準地走錯方向。

Reality → Language → Model → Prediction → Action → Result → Feedback → Update

Language shapes the entire feedback loop.
Distortion at the start means precise movement in wrong direction.
